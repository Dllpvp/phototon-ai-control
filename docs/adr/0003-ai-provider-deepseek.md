# 0003. Миграция AI-провайдера на DeepSeek (Klinch Cloud)

Дата: 2026-11-07
Статус: Принято

## Контекст
Оригинальная спецификация предполагала использование Google Gemini API. Однако в инфраструктуре РФ и для целей стабильного демо на жюри Google Services / Gemini API могут быть недоступны или заблокированы.

## Решение
Перейти на использование DeepSeek через OpenAI-совместимый API провайдера Klinch Cloud (`https://api.klinch.cloud/v1`).
Сохранить всю существующую архитектуру кэширования (`ai_cache.json`), детерминированного валидатора (`validate`) и оффлайн-фоллбека (`offline_mode`), подменив лишь транспортный слой интеграции на `openai` клиент.

## Последствия
- Обеспечена 100% стабильность работы AI-интерпретатора на презентации независимо от блокировок Google.
- Полностью сохранены контракт DTO (`AiDTO`) и тесты гарда.
